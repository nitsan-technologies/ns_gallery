==========
NS Gallery
==========

:Extension key:
    ns_gallery

:Package name:
    nitsan/ns-gallery

:Rendered:
    |today|

----

EXT:ns_gallery is a TYPO3 extension which allows website administrators to add beautiful galleries to their website. EXT:ns_gallery provides a variety of galleries to choose from and allows administrators to present media to website users in the best possible way. Galleries in this extension are not limited to just images and also allow adding self-hosted videos, YouTube videos & Vimeo videos.
