============
Introduction
============

EXT:ns_gallery is a TYPO3 extension which allows website administrators to add beautiful galleries to their website. EXT:ns_gallery provides a variety of galleries to choose from and allows administrators to present media to website users in the best possible way. Galleries in this extension are not limited to just images and also allow adding self-hosted videos, YouTube videos & Vimeo videos.

..  figure:: ../Images/ext_banner.jpg
    :alt: Extension banner

What does it do?
================

EXT:ns_gallery is a comprehensive gallery solution for TYPO3 that offers multiple display styles and media support. The extension provides administrators with flexible options to showcase content through various gallery layouts, ensuring the best presentation for different types of media.

Available Gallery Types
=======================

The extension offers the following gallery types:

**1. Album View (Open in same/new page)**

Create organized albums that can open content in the same page or redirect to new pages for detailed viewing.

**2. Masonry View**

Display media in a dynamic masonry layout with responsive grid arrangements that adapt to different screen sizes.

**3. Isotope View**

Advanced gallery with filtering and sorting capabilities, allowing users to organize content by categories or criteria.

**4. Mosaic View**

Create stunning mosaic layouts with tile-based arrangements for modern visual presentations.

**5. Slider View & Carousel View**

Interactive sliders and carousels with navigation controls, autoplay options, and smooth transitions.

**6. Google Search View**

Integrate Google search results to display images from external sources within your gallery.

**7. Zoom View**

Enhanced viewing experience with zoom functionality for detailed image inspection.

Features
========

*   Multiple gallery layout options
*   Support for images, self-hosted videos, YouTube and Vimeo videos
*   Responsive design for all devices
*   Backend module for easy management
*   Flexible configuration options
*   Modern and attractive designs
*   SEO-friendly implementation
